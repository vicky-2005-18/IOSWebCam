## Context Summary

iOS WebCam Bridge is a real-time video streaming system that repurposes iOS devices as virtual webcams for Windows desktops. The project uses a web-based approach (no native iOS app) with HTML5 MediaDevices API for camera capture, WebSocket binary transmission for low latency, and PyVirtualCam for DirectShow integration.
